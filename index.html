Pasang Aplikasi Gudang
Gudang Elektrik Inventory App
Cara Pasang di HP Android (Chrome)
  1. Buka halaman ini di browser Google Chrome ponsel.
  2. Ketuk ikon menu titik tiga (⋮) di pojok kanan atas browser.
  3. Pilih "Instal Aplikasi" atau "Tambahkan ke Layar Utama".
  4. Ikon Gudang Elektrik akan terpasang di HP Anda & terbuka fullscreen tanpa kolom URL browser.
Cara Pasang di iPhone / iPad (Safari)
  1. Buka halaman ini di browser Safari iOS.
  2. Ketuk tombol Bagikan (Share) berupa ikon kotak panah atas (⬆️) di bawah layar.
  3. Gulir ke bawah dan ketuk "Tambah ke Layar Utama" (Add to Home Screen).
File APK Android Mandiri Tersedia
File GudangElektrik.apk siap diinstal langsung tanpa browser.
